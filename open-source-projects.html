01 / Local-first career toolkit v0.2.0 pre-release

ReboundOps

A privacy-conscious job search workspace that works without an account — or AI.

ReboundOps brings job intake, explainable fit assessment, evidence-based resume tailoring, application tracking, and follow-ups into a workspace that runs on your own computer. AI is optional, and consequential actions stay with the user.

What it helps you do

  • Collect postings and assess role fit with an explainable rubric and separate eligibility checks.
  • Draft tailored resumes and cover letters from user-verified facts, with PDF and DOCX export.
  • Track applications, follow-ups, and interview notes without auto-submitting or sending messages.

Engineering approach

  • Angular frontend, Fastify API, and local SQLite storage built around explicit data contracts.
  • Optional local Ollama or consent-based cloud AI providers; the core workflow does not require AI.
  • Designed for evidence, privacy, reversible decisions, and user approval rather than opaque automation.
  • Angular
  • TypeScript
  • Fastify
  • SQLite
  • Ollama optional

02 / AI-assisted desktop workspace Source build available

AI Job Search Assistant

A visual macOS command center for guided, reviewable job-search workflows.

A desktop interface built around the open-source ai-job-search workflow. It makes discovery, ranking, application preparation, and tracking easier to see and manage, with tool activity and approval steps visible before sensitive actions.

What it helps you do

  • Follow discovery, ranking, drafting, review, and tracking through a dedicated desktop UI.
  • Inspect resumes, cover letters, and agent activity instead of relying on hidden automation.
  • Keep the human in control of file and command approvals; applications are not auto-submitted.

Engineering approach

  • React 19 interface with a Tauri 2 and Rust host for an Apple Silicon macOS experience.
  • Local workspace integration with SQLite used for application settings and run history.
  • Claude Code and OpenAI Codex integrations described in the repository; check docs for provider status.
  • React
  • TypeScript
  • Tauri 2
  • Rust
  • SQLite
  • Claude Code / Codex
